How it works

Lightweight by design

1

Paste an address

Any 0x… EVM address. We validate the format locally before querying DeBank or the public-chain fallback.

2

We query DeBank or explorers

On Vercel, an optional same-origin serverless function calls DeBank's all-chain token endpoint. The DeBank AccessKey stays server-side; if it is not configured, we use public Blockscout APIs and public RPCs instead.

3

Only real balances

Zero balances are dropped. DeBank's indexed amounts and USD prices are used when configured; public chain data is the fallback. Prices are estimates, not guarantees.

4

Continue on Debank

Every result links to debank.com/profile/{address} — overall and per-chain — for DeFi positions, NFTs, history and the full portfolio.
